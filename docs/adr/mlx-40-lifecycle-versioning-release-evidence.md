# MLX-40: Lifecycle, Versioning and Release Evidence

Active collections use protected `develop` integration and reviewed promotion to
stable `main`. Release evidence binds the exact promoted revision, checks,
artifacts, and publication result. Archived or deleted repositories do not
receive active quality-policy gates.

This public summary is distributed with the managed collection quality policy.
The controlled internal decision record remains the approval authority.
