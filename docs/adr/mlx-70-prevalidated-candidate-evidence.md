# MLX-70: Prevalidated Candidate Evidence and Asynchronous Heavy Execution

Heavy and application-acceptance results must bind the exact candidate artifact
or tree, policy, matrix, and validation run. Protected `main` consumes that
bounded evidence; it must not convert a missing, stale, or skipped result into a
passing release gate.

This public summary is distributed with the managed collection quality policy.
The controlled internal decision record remains the approval authority.
