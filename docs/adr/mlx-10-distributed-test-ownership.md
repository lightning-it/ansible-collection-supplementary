# MLX-10: Distributed Test Ownership and Central Heavy Execution

Fast, deterministic, secret-free checks belong to the collection repository and
run for pull requests. Heavy, infrastructure-dependent, or credentialed tests
belong to `lightning-it/modulix-validation`; collection workflows consume their
candidate-bound evidence instead of duplicating protected infrastructure.

This public summary is distributed with the managed collection quality policy.
The controlled internal decision record remains the approval authority.
